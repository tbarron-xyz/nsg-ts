# numerical-monoid

A TypeScript library for computational algebra focused on numerical monoids (also known as numerical semigroups). Numerical monoids are sets of non-negative integers closed under addition, generated by a finite set of numbers. This library provides algorithms to compute key properties such as factorizations, Frobenius numbers, Betti elements, catenary degrees, and minimal spanning trees using graph-based approaches.

## Features

- **Factorizations and Membership**: Compute all ways to express numbers as sums of generators, and check membership in the monoid.
- **Frobenius Number**: Find the largest number not in the monoid.
- **Betti Elements**: Identify elements with disconnected factorization graphs.
- **Catenary Degrees**: Calculate the minimum distance to connect all factorizations via graph metrics (e.g., Euclidean or "classic catenary" distance).
- **Minimal Spanning Trees**: Use Kruskal's algorithm to compute MSTs for factorization graphs.
- **Graph Visualization**: Integrates with Cytoscape for graph-based computations.
- **Caching**: Efficient memoization for repeated computations.

## Usage

### Basic Example

```typescript
import NumericalMonoid from './NumericalMonoid';

const generators = [11, 12, 14];
const monoid = new NumericalMonoid(generators);

// Check if 25 is in the monoid
console.log(monoid.hasElement(25)); // true or false

// Get all factorizations of 25
console.log(monoid.factorizations(25)); // e.g., [[0,1,1], [1,0,1]]

// Compute Frobenius number
console.log(monoid.frobenius()); // e.g., 10

// Compute catenary degree for n=100 using classic metric
const catenaryDegree = monoid.catenaryDegreeByMetric(100, NumericalMonoid.distanceForClassicCatenary);
console.log(catenaryDegree);
```

### Advanced Example: Betti Elements and Catenary Bounds

```typescript
const monoid = new NumericalMonoid([11, 12, 14]);

// Get Betti elements
const betti = monoid.bettiElements();
console.log(betti); // e.g., [23, 34, ...]

// Check catenary bound hypothesis (Euclidean metric)
const satisfiesBound = monoid._satisfiesCatenaryBoundHypothesisEuclidean();
console.log(satisfiesBound); // true or false
```

## Project Structure

- **`NumericalMonoid.ts`**: Core class with monoid operations, caching, and graph computations.
- **`lib/kruskal.ts`**: Implementation of Kruskal's algorithm for minimum spanning trees.
- **`lib/union-find.ts`**: Union-find data structure for efficient MST operations.
- **`Hash.ts`**: Custom hash set for caching factorizations.
- **`utils.ts`**: Utility functions (e.g., GCD, distance calculations).
- **`browser/`**: Browser-compatible build for demos and visualizations.
- **`docs/`**: Static documentation site.
- **`main.ts`**: Example computations and entry point.

## API Reference

### NumericalMonoid Class

- `constructor(generators: number[])`: Initialize with a sorted array of generators.
- `factorizations(n: number): Factorization[]`: Returns all factorizations of `n`.
- `hasElement(n: number): boolean`: Checks if `n` is in the monoid.
- `frobenius(): number`: Computes the Frobenius number.
- `bettiElements(): number[]`: Returns Betti elements.
- `catenaryDegreeByMetric(n: number, metric: Metric): number`: Catenary degree using a custom metric.
- `minimalSpanningTreeByMetric(n: number, metric: Metric): [number, number][]`: MST as index pairs.
- `percent_of_edges_that_are_minimal(n: number, metric: Metric): number`: Fraction of minimal edges in MST.

### Static Methods

- `NumericalMonoid.distanceForClassicCatenary(fac1: Factorization, fac2: Factorization): number`: Classic catenary distance.

## Background and References

This library is for research in commutative algebra and number theory. Numerical monoids are studied for their factorization properties, with applications in cryptography and coding theory.

- **Related Concepts**: Frobenius numbers, catenary degrees (introduced by S.T. Chapman), Betti elements.
- **Papers and Researchers**: Key contributors include J.C. Rosales and P.A. García-Sánchez (e.g., "Numerical Semigroups" book), J.I. García-García, A. Assi, and others in the semigroup theory community. See works on catenary degrees by S.T. Chapman and computational aspects by the Granada semigroup group.
